# ABIS GUI 管理控制台

ABIS 生物识别系统的配套管理控制台前端。纯静态 SPA，无自有后端，全部数据经管理 API 获取。

## 运行

### 混合接入预览（2026-10-27）

运行 `npm run dev:hybrid`，使用后端真实账户登录。开发服务器通过 `/admin-api` 代理到 `http://10.200.51.121:7002`，需要当前机器能访问该内网地址。可在 `.env.hybrid.local` 中覆盖 `ABIS_PROXY_TARGET`；不在前端写入真实密码。

- 登录/注销、监控、阈值读写、日志/审计查询走真实接口。真实接口失败或结构不匹配时展示错误，不会回落 mock。
- 账户列表读取真实 `/system/user/console-page`，支持分页及用户名、姓名搜索，不混入演示账户或临时记录。新增、编辑、启停、删除、重置使用真实接口，操作成功后重新读取列表；角色、启用状态筛选尚未提供给页面。
- 账户页面按两类职责显示操作：管理员可管理全部账户，运维员可查看列表、重置运维员密码。界面限制不能代替后端校验，运维员的真实权限与完整账户写入行为仍待验证。
- 新增账户暂只发送现有文档明确的用户名、姓名和角色；重置按当前接口发起无请求体调用，不提供尚未确认支持的密码输入。后端返回密码时在结果弹窗单独展示，关闭即清除；未返回时明确提示密码规则及交付方式待确认。未接入缺少后端入口的本人改密功能。
- 两类 CSV 导出仍使用独立 Mock 样本，按钮和文件名均标记 Mock，不代表真实列表导出。
- 当前浏览器标签页的有效会话通过 `/system/auth/get-permission-info` 恢复，刷新后重新校验身份；认证失效时清理会话并回到登录页。登录响应没有可识别角色时，显示“角色待后端提供”，仅开放读取预览。
- 保留原阈值下限校验；日志和审计发送页面全部非空筛选参数，是否生效需后端联调确认。未接入业务侧人脸注册接口。

检查：`npm test`；预览构建：`npm run build:hybrid` 后运行 `npm run preview:hybrid`。静态部署需要另行配置 `/admin-api` 反向代理（Vite 代理不会被打包进静态文件）。此版本为混合预览，不作为正式交付版本。

目前转换支持 `{code,data,msg}` 包装及 `detail` 错误，列表支持 `items/list/records + total`。真实登录、账户列表、身份查询、注销及其他管理读取接口已验证；账户写操作的页面流程检查与后端实际写入验收分开记录，不能将前端测试通过视为后端写入通过。

### 原纯 Mock 演示

```bash
npm install
npm run dev
```

## mock 与真实接口的切换

编辑 `.env.development`：

- `VITE_USE_MOCK=true` —— 走 mock 适配器，数据由 `src/mock/` 生成（**当前默认**）
- `VITE_USE_MOCK=false` —— 走真实 HTTP 适配器，调用 ABIS 管理 API

切换时**页面代码无需改动**，只需替换 `src/api/adapters/` 下的实现。

> 上面的 `.env.development` **只对 `npm run dev` 生效**，对生产构建无效 —— 见下一节。

## ⚠ 生产构建（部署前必读）

**当前工程没有 `.env.production`，所以直接 `npm run build` 打出来的产物会走 mock 适配器。**

Vite 的 env 加载规则是：`npm run build` 以 `mode=production` 运行，**不加载** `.env.development`。
于是生产构建里 `VITE_USE_MOCK` 是 `undefined`，而 `src/api/index.js` 的取值逻辑是
「非 `'false'` 即视为 mock」，结果落到 mock。

**这个失败不报错、不报警**：产物照常登录、照常有数据、界面上没有任何异常迹象，但全是假数据，
而且演示凭据（`admin`/`admin123`、`ops.zhang`/`ops123`）已经被编进 JS 里，谁都能用它登进去。
它长得和正常一模一样，所以最难发现。

契约冻结、准备交付时：

1. 新建 `.env.production`，显式写：

   ```
   VITE_USE_MOCK=false
   ```

2. 构建后**确认真的走了真实适配器**：`npm run preview` 打开页面，在浏览器 Network 面板里
   应看到对 ABIS 管理 API 的真实请求。若**一个请求都没有**，说明还在 mock 上。

3. 在真实认证接通之前，**任何 `dist/` 都不得对外部署。**
