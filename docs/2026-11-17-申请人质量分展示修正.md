# 2026-11-17 申请人质量分展示修正

依据用户对申请人详情质量分混乱的反馈及后续澄清，抽屉缩略图下方只显示分值，点击图片后的详情表格保持不变。本轮保留其他未提交改动，未提交 Git。

## 检查与修正

此前人脸色条带「质量分」，指纹仅显示裸数字，字段名放在组标题旁，窄屏滚动后容易失去归属。放大预览又在图片下方和信息表中重复显示分值。缺失分值颜色偏淡，实测对比度仅 3.411:1。

核对 U001、U004、U301、U302、U006 后，图像、质量分和图像更新时间与最新有效入库记录对应正确，未发现串值。本轮修正展示方式，保留原分值及选取规则：

- 每张人脸和指纹缩略图下方居中显示实际分值（如「92」），不再显示「质量分」文字。移除指纹组标题旁的孤立标注。
- 缺失分值显示「—」，加深文字颜色，保持「质量分未提供」的悬停、键盘聚焦提示；实际 0 分继续显示 0。
- 点击图片后的详情表格保持本次澄清前的内容与样式，包括质量分和缺失状态；预览图片下方不重复显示色条。
- 有效分值加入图像按钮的无障碍名称；未入库卡位仍没有质量分条或放大入口，列表缩略图保持原样。
- U301 重复左手食指继续选最新有效的 97 分记录；缺失分值和 0 分不混用。
