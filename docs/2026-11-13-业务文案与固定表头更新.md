## 访问与专用验收入口

使用 Node 22.23.4 或兼容版本，在项目根目录启动：

```bash
npm run dev:mock -- --host 0.0.0.0
```

其他电脑访问 `http://<服务器IP>:5186`。服务状态 `/monitor`，主机资源 `/host-resources`，申请人 `/applicants`，日志 `/logs`，审计 `/audits`，阈值 `/threshold`，账户 `/accounts`。

验收账户：管理员 `admin / admin123`，运维员 `ops.zhang / ops123`。页面已移除账户说明、环境徽标及运行模式说明。本人改密成功后须重新登录；修改的密码在当前浏览器模块会话内有效，完整刷新会恢复初始验收密码。

重采入口为 **`http://<服务器IP>:5186/acceptance/recapture`**，需要登录及申请人查看权限，仅在 Mock 模式提供，不进入常规导航。可切换 U301 / U302 / U303 的旧数据有效、双模态删除、新人脸入库、重采结果，通过「查看申请人列表」查看该状态。U900 保留在可展开区域，支持原流程及指纹失败状态。点击「恢复默认数据」恢复初始快照。

自动化已恢复默认数据；初始列表为 9 位申请人，含 U301 的 8 个指位和 U302 的 10 个指位。状态切换在同一浏览器页面的前端路由之间保留，完整刷新会重建默认快照。默认日志范围为 15 条，按完整用户或请求 ID 查询可以访问历史与补充记录。U301 / U302 / U303 重采历史日期为 2026-11-12，普通请求时间随初始化时刻生成。审计样例日期覆盖 **2026-09-13 至 2026-09-14**，可按完整账号 `ops.zhang` 及「登录＋结果」查询。

## 本轮修改

| 范围 | 行为与主要文件 |
| --- | --- |
| 文案与空间 | 登录页、顶部导航、申请人、日志、审计、阈值、账户和个人信息移除文档列出的说明及空容器；保留业务校验、空状态、异常原因和图像时点提示。对应 `LoginView.vue`、`AdminLayout.vue`、各业务 View、`ProfileDialog.vue`、`EnrollmentImage.vue`、`RequestLogMessages.vue`。 |
| 三页列表 | 新增 `src/composables/useRecordsTable.js`，三页表格按视口剩余高度限制最大高度，表头与工具条保持在原处，记录内部滚动。短列表保持自然高度；查询、分页和排序重置记录滚动。申请人返回详情时恢复表格内部滚动位置。对应三个查询 View 及 `src/stores/applicants.js`。 |
| 最新指位记录 | `src/utils/applicant.js` 按成功入库时间、同时间写入顺序取最新记录。列表、详情及当前图像查询共用规则；移除多记录选择器和条数标记，保留原始入库变更历史。对应 `ApplicantDetailDrawer.vue`、Mock 适配器及图像素材。通用 SVG 已移除全部用途水印。 |
| 异常追溯 | `RequestLogDrawer.vue` 区分当前异常与历史异常。REQ-00000017 显示「查重成功 · 重试后完成」，从「历史异常」定位第一次 CONNECT_TIMEOUT，保留两次尝试各自正文。REQ-00000012 继续从「查看事件」定位 PUBLISH_NACK。 |
| 重采验收 | 新增 `RecaptureAcceptanceView.vue` 和受保护的 `/acceptance/recapture` 路由；常规申请人列表移除全部重采切换入口。 |

日志工具条仅保留靠右的 CSV 导出，总数在分页区展示；悬停提示为「导出当前查询的全部日志字段」。日志及审计继续使用已生效查询条件导出全部分页，日志接收时间保留毫秒。
