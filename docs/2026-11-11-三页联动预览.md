## 共享数据与请求样例

`src/mock/business.js` 为日志和申请人提供同一次生成的业务快照。U004–U008 的既有入库记录与当前请求同属一套数据；成功注册和删除按 ABIS 业务结果更新有效记录，响应发布失败不撤销已确认业务结果，查重及失败请求不修改已有记录。

| 请求 | 用户 | 模态及操作 | 展示 |
| --- | --- | --- | --- |
| REQ-00000001 | U001 | 人脸注册 | 业务成功并发布；顶部并排显示请求总耗时 320 ms、ABIS 接口处理耗时 180 ms；三个顶层阶段为 20 / 210 / 40 ms。 |
| REQ-00000002 | U001 | 指纹注册 | 成功入库 10 条；U001 与人脸合并为一名有效申请人。 |
| REQ-00000003 | U001 | 人脸查重 | 成功，候选为空。 |
| REQ-00000004 | U001 | 指纹查重 | 成功，候选为空。 |
| REQ-00000005 | U002 | 人脸注册 | 成功。 |
| REQ-00000006 | U002 | 人脸查重 | 命中 U001，列表 userId 仍为 U002。 |
| REQ-00000007 | U002 | 人脸删除 | 删除 U002；保留历史请求，不删除已有候选人 U001。 |
| REQ-00000008 | U003 | 人脸注册 | 响应超时、待人工核查；不计为有效申请人，不生成后续调用。 |
| REQ-00000009 | U004 | 人脸查重 | ACK 异常/重投留在原请求，Worker 继续调用；既有入库记录不变。 |
| REQ-00000010 | U005 | 指纹查重 | 确认未发出的连接超时，等待重试，保留原入库图像。 |
| REQ-00000011 | U006 | 人脸查重 | ABIS 明确失败，发送/调用/发布成功；原入库记录和时间不变。 |
| REQ-00000012 | U007 | 指纹查重 | 业务成功但待发布，耗时仍为已用时。 |
| REQ-00000013 | U008 | 同步人脸删除 | 单个 ABIS_HANDLING，删除后不在当前申请人列表。 |

日志按完整 userId/requestId 查询，接口筛选同时覆盖该接口的人脸和指纹；两页均读取入口 Event 的字段，候选人仅留在响应正文。异步 Stage 的纵向连线表示业务顺序。“阶段概览”默认折叠，各行左侧为名称、右侧为状态和耗时；展开后阶段代码与起止时间同一行显示，同日只保留一次日期，跨日显示起止完整日期；窄屏可换行，保留毫秒精度。请求 ID 单元格仅保留编号，业务结果摘要在抽屉顶部信息表格中单独占一行，位于“执行状态”下方，查重成功时按实际响应显示候选数量，无响应正文时不虚构候选数。展开后的 Event 按实际发生时间显示毫秒级时间、节点和纵向连线；ABIS_HANDLING 是对应尝试中的紧凑可展开行，正常位于发起调用和收到响应之间，显示自身状态与 180 ms 阶段耗时。继续展开保留接收请求、业务处理、发送响应三项。迟到日志的采集时间不参与排序，重投和多次调用保留在原 Stage；缺少 ABIS 开始记录时不借用调用时间。极窄屏自动将时间放在动作上方，避免挤压正文。正常 Event 精简成动作和结果，去掉重复的动作说明；发起调用和发布只在标题显示一次尝试编号，不再附加“已开始”标签。ACK 标注“落库后”，取得 CALLING 标注“本次调用前”，发布确认显示“MQ 已确认发布”。响应区固定在抽屉底部，默认直接显示格式化 JSON，按尝试和时间选择多份正文，无正文时保留占位。

## 申请人复查

- U001：人脸 1 条、指纹 10 条；首次入库为第一次人脸业务注册成功，最近更新为指纹业务注册成功。左、右手各五指排列，点击任一缩略图核对放大图、记录 ID、更新时间和指位。
- U004：只有预置人脸，指纹显示未入库；列表“查看日志”定位 ACK/重投请求。
- U005：只有预置指纹；左手食指有两条绑定不同本地图像的记录，可在指位内切换。右手拇指有有效记录但图像不可用，仍保留记录信息和数量。
- U006：预置人脸，失败查重不改变入库数量、图像或更新时间。
- U007：预置指纹，响应发布待重试不影响原有效记录。

只有列表行提供申请人级“查看日志”。图像详情中只有明确关联 requestId 的记录提供“查看本次入库日志”，例如 U001 的指纹记录定位 REQ-00000002。返回列表恢复筛选、排序、页码和真实纵横滚动位置。

模态筛选为全部、仅人脸、仅指纹、双模态，后三种互斥。首次入库时间筛选支持组合；首次入库及最近更新时间都在全量匹配记录上排序后分页。图像为 `public/mock/biometrics/` 内每条记录绑定的本地 SVG 示意样例，不引用外部图片；缺失和加载失败均显示图像不可用。

- 算法服务 1：face-1 异常，fingerprint-1 正常。
- 算法服务 2：face-2、fingerprint-2 正常。
- PostgreSQL：postgresql-1、postgresql-2、postgresql-3 正常。
