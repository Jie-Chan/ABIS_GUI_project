# 2026-11-16 视觉与宽屏布局优化

本记录中的监控刷新入口及探测时间展示已由后续文档调整，最新监控行为见 [监控自动更新与卡片对齐](2026-11-16-监控自动更新与卡片对齐.md)。

2026-11-17 阈值配置更新：根据开发文档 §5.1、§10.4，已取消主卡片 960px 最大宽度，改为左右铺满页面内容区；桌面两项等宽并排占满表单，窄屏单列。下文的 960px 实测及阈值截图为此前版本记录。

依据 [开发文档](<20261116-ABIS mock界面开发文档.md>) 第 10 章。保留既有排序、查询快照、日志关联、图像预览、会话与权限规则，本轮未提交 Git。

## 界面变化

- 日志、监控、审计和账户状态统一使用深色文字与浅色底色；成功、失败、待关注、中性、处理中分别使用第 10 章配色。诊断及次级说明使用可读颜色，监控故障原因、请求核查指引和阈值协议说明使用 13px。
- 监控异常及未知条目的状态、原因、主机入口相邻，探测时间和部署信息位于次级行。保留主机定位的浅蓝底和左侧蓝线。
- 请求详情前三行依次展示请求 ID 与复制入口、两类状态、业务摘要与错误码/查看事件；待人工核查紧接指引。申请人、接口、接收时间、调用方式、耗时位于下方紧凑信息区。同步请求继续省略发布状态和重复的处理耗时。
- 桌面重新分配日志列宽及内边距，常见人脸/指纹查重名称完整成行，来源 IPv4 保持单行。接口和 IP 允许超长省略，悬停或键盘聚焦可读完整值。
- 1024 保留关键列优先布局。横向溢出时底部滚动条持续可见，表头与内容同步。624 初始位置优先展示请求 ID、执行状态、发布状态，详情固定在右侧；接收时间排序及其他列通过横向滚动访问。
- 窄屏常用导航保留，设置归入「更多」，可进入阈值及账户管理；当前设置模块有名称和高亮，导航可自然换行，无需横向滚动。
- 匹配阈值主卡左对齐、最大宽度 960px，内部两组等宽；窄屏继续单列。短表单后的区域为页面背景。日志、审计、账户表格继续按可用宽度布局，长表随窗口增高显示更多内容，短表和空结果随内容收缩。
- 全正常、全部筛选且服务/存储数据完整时，1440 × 900 和 1920 × 1080 监控页利用可用首屏高度。异常、未知及少量筛选结果按自然内容排布。默认 Mock 的异常和未知样例不改动，全正常验收通过临时监控快照完成。
- 申请人详情的共用「质量分」标注紧邻指纹标题和指位数；列表缩略图、十指占位、缺失分值和实际 0 分保持原规则。

## 对比度方法

按浏览器计算后的文字颜色与实际合成背景测量，不以截图抗锯齿像素推算。普通、表格悬停、卡片及抽屉分别检查，阈值按文档要求使用未四舍五入的 4.5:1；方法参考 [W3C Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

## 验证记录与截图

使用本机 Node 22，`npm run build:mock` 和 `git diff --check` 通过。下列检查共 52 项通过，浏览器错误及真实后端调用均为 0；重复执行的同一用例不重复计数。

| 检查 | 通过项数 | 覆盖 |
| --- | ---: | --- |
| 新增 `review-visual-20261116.mjs` | 11 | 第 10 章实际颜色/背景、摘要层级、1280/1024/624表格与导航、监控诊断、阈值、长短表、全正常首屏、图像占位及质量分 |
| `review-request-logs.mjs` | 26 | 请求身份、状态、事件/报文、耗时、筛选/CSV、分页/抽屉及 320～1920 宽度 |
| `review-ux-20261116.mjs` | 15 | 排序及键盘、条件快照、跨页/滚动恢复、核查/复制、关联跳转、质量提示、审计、监控及会话契约回归 |

实测记录：

- 33 次对比度抽样最低 4.729:1（普通蓝色入口），五类状态标签最低 5.365:1；普通、悬停、卡片及抽屉分别验证。
- 全正常监控页在 1440 × 900 下存储区底边为 852px，1920 × 1080 下为 1032px，两者底部均留 48px，三组服务卡及四条存储记录完整可见。
- 阈值卡片在两种桌面视口下均为 960px。短账户卡片约 482px，窗口增高后保持自然高度；长审计表可视区由 590px 增至 770px，可见完整记录由 10 行增至 13 行；空日志卡片约 384px。
- 质量分标注与标题水平间隔为 12px，不依赖抽屉宽度推至最右；普通分值、缺失值及 0 分的缩略图与预览一致。

在 `frontend-toolkit/verification` 下可运行 `ABIS_PREVIEW_URL=http://127.0.0.1:5186 npm run test:visual`。新专项接入了 `test:current` 及完整测试链，相关旧检查已同步摘要位置和窄屏设置入口。原始报告及临时截图位于被 Git 忽略的 `qa-output/visual-20261116/`，回归日志为 `qa-output/chapter10-request.log`、`chapter10-ux.log`。
