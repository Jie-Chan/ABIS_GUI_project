## 配置与启动

服务端在 Mock 启动时读取 [`config/beszel.json`](../config/beszel.json)。交付配置的 Hub 为 `http://10.200.51.121:8090`，映射为 `app-1` → `vgrg02yzsr69lc7`。其他主机可在同一 Hub 为账号授予读取权限后，在 `hosts` 添加对应的 `hostId` 和 `systemId`。

将 `ABIS_BESZEL_USERNAME` 和 `ABIS_BESZEL_PASSWORD` 注入进程环境，或保存在 Git 忽略的 `.env.demo.local`。已有合法会话可用可选的 `ABIS_BESZEL_TOKEN`。配置文件中的 `usernameEnv`、`passwordEnv`、`tokenEnv` 记录这些变量的名称。实际联调返回的页面、接口和凭据文件访问均已检查。

使用 Node.js 22，在工程根目录执行以下命令。修改配置或凭据后，停止原 Mock 进程并再次执行命令加载。[启动后访问主机资源](http://10.200.51.121:5186/host-resources)

```bash
npm run dev:mock -- --host 0.0.0.0
```

页面使用同源 `GET /abis-admin/monitor/hosts`，如 `?range=1w`。省略 `range` 使用 `1h`，非法值返回 HTTP 400。`items` 按配置返回映射主机。读失败时 `sampleError` 或 `historyError` 分别标记分钟查询和历史查询的结果，成功空窗用空数组表示。轮询和重试读取当前档位，图表点选直接使用已返回的历史记录。[Beszel v0.21.2 档位定义](https://github.com/henrygd/beszel/blob/v0.21.2/internal/site/src/lib/utils.ts#L119-L168)
