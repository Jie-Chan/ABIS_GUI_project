## 在服务器上恢复与启动

先在本机提交并推送当前前端改动、工具目录、文档和截图。在新服务器将 YOUR_REPOSITORY_URL 替换为实际 GitHub 仓库地址：

```bash
git clone --branch front-end YOUR_REPOSITORY_URL ABIS_GUI_project
cd ABIS_GUI_project
git status --short --branch
```

新服务器只会拿到已提交且已推送的内容。克隆后核对提交号和目录，确认 frontend-toolkit 与第二版界面均存在，再开始开发。

从工程根目录安装推荐技能：

```bash
bash frontend-toolkit/install-skills.sh
```

使用 Node.js 22.23.2 可复现本次环境；当前 Vite 的引擎声明为 `^20.19.0 || >=22.12.0`。

```bash
npm ci
npm run dev:mock -- --host 127.0.0.1
```

服务固定监听 5186。管理员为 `admin / admin123`，运维员为 `ops.zhang / ops123`。

如果通过 SSH 访问，可在本地另开终端，用不同的本地端口建立转发：

```bash
ssh -N -L 15186:127.0.0.1:5186 user@your-server
```

将用户名与服务器地址替换为实际值，然后打开 `http://localhost:15186/login`。也可以在 VS Code Remote SSH 中将服务器 5186 转发为本地 15186。确认页面显示「Mock 演示数据」，并且 admin/admin123 可登录。

此前 Windows 的 localhost:5174 被 VS Code 转发到了另一份 hybrid 服务，导致打开了错误版本；该联调服务未修改。不要沿用旧书签判断新服务是否正常。

构建验证使用 `npm run build:mock`。本轮迁移用于继续开发，正式部署时再处理真实认证、API 反向代理和 SPA 路由回退等事项。
