# 2026-11-16 申请人全高抽屉与图像比对更新

依据 [11 月 16 日开发文档](<20261116-ABIS mock界面开发文档.md>) §1.4、§1.9、§2.2、§2.3，以及补传的 [申请人全高抽屉设计示意](20261116-ABIS申请人全高抽屉设计示意.png)。本轮保留此前登录页、调用方式、查询及其他未提交改动，不提交 Git。

## 界面变化

- 申请人详情靠右贴齐视口上下边缘，右上角关闭始终可用；超长内容在抽屉内滚动。移除底部重复关闭按钮，白色内容区在最后一项下方保留 24 px，其余区域为浅蓝灰底。
- 人脸框与左右手十个指位固定保留，每手按拇指、食指、中指、无名指、小指排列。U301 展示 8 张有效图及 2 个缺采占位，U004 为 6 张及 4 个占位，U006 为「指纹 0 指」及十个占位；U303 指纹重采失败后同样保留十个空卡位。
- 缺采指位使用等高浅色虚线框和「—」，无质量分条、无放大入口；无障碍名称保留完整手别、指位及未入库状态。无人脸记录时，在人脸框内显示「未入库」。
- 1440 × 900 下，指纹预览框含质量分条为 170 px；较矮或较窄视口使用紧凑尺寸。保留按最新有效记录选择图像、质量分及更新时间的规则，质量分缺失显示「—」，有效值 0 保留。
- 图像使用原始比例完整居中显示。已有入库记录但图像不可用时显示「图像不可用」，保留已记录质量分及无障碍信息，并移除无法使用的放大入口。
- 日志「图像比对」移除独立提示横幅，将「图像为当前入库版本」放在候选切换行右侧，两侧图像共用一处。空间不足时说明换行；无候选按钮但有可用图像时，说明放在图像区上缘。「本次响应」、候选排名及分数继续保留。

## 验收入口

沿用现有 `npm run dev:mock -- --host 0.0.0.0`，访问服务器的 5186 端口。管理员 `admin / admin123`。本轮独立测试使用临时 5187，完成后停止，用户现有 5186 服务不作启停。

申请人列表直接查看 U301、U004、U006；登录后访问 `/acceptance/recapture` 可切换 U303 等重采样例，验收后恢复默认状态。日志通过请求 ID 查询 `REQ-00000014`（指纹三候选）或 `REQ-00000015`（人脸三候选）。

## 验证记录

使用本机 Node 22，`npm run build:mock` 和 `git diff --check` 通过。

- `review-applicant-image-labels.mjs`：5 项通过，覆盖最新图像与质量分、十卡占位、内部编号隐藏、坏图无放大及缺失/零分。
- `review-console-20261113.mjs`：18 项通过，回归筛选、列表滚动、申请人变更与精确日志联动、重采及导出等。
- `npm run test:current` 中原有 `review-console-20261116-followup.mjs`：8 项通过，保留调用方式、审计、阈值及窄屏布局回归。
- 新增 `review-console-20261116-images.mjs`：7 项通过。覆盖 1440 × 900、1422 × 804、1280 × 720、1280 × 640 和 624 × 850，核对来源说明同行/换行、十卡布局、缺采及无人脸状态、坏图、等比预览、内部滚动与日志返回。边界样例使用临时 API 数据，验证后恢复。
- `review-log-images.mjs`：16 项通过，回归候选切换、当前入库图像、无候选/处理中/失败状态、图像读取失败及放大预览。
