# ABIS GUI 第一版 Mock 界面

本版位于 `front-end` 分支，按已确认的监控页与登录页示意图实现，供界面审阅。

## 打开预览

使用 Node.js 22.12+ 或满足当前 Vite 要求的版本，运行：

```bash
npm run dev:mock -- --port 5174
```

访问 `http://localhost:5174`。管理员演示账户为 `admin / admin123`，运维员为 `ops.zhang / ops123`。

`npm run build:mock` 使用现有 `.env.demo` 构建 Mock 版本；构建完成后可用 `npm run preview:mock` 查看产物。

## 改动范围

- 新增统一主题、品牌标记、SVG 图标和数据来源提示。
- 监控概览从现有快照派生统计；未部署不计入异常，读取失败时标明保留上次数据。
- 登录页在 Mock 模式展示演示账户，HTTP 模式隐藏演示凭据，不宣称后端已经连接。
- 统一表格、筛选栏、表单、详情和确认弹窗的视觉样式。
- `src/api/`、`src/stores/`、`src/router/`、业务常量和 `src/mock/` 均未修改；现有业务处理函数保持原样。
