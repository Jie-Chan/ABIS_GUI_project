# ABIS 账户管理后端接口开发文档

本文用于账户管理及相关认证接口的前后端开发对接。接口按下述约定设计，尚未确定的参数见末节。

实现状态核对日期：2026-10-27。依据：[同事提供的 Apifox 文档](../test.apifox.json)、[当前服务 OpenAPI](http://10.200.51.121:7002/openapi.json)及测试账户的读取、登录和注销请求；未进行后端源码审阅或账户写入测试。

标记说明：“已验证”表示实际请求通过；“入口已提供”仅表示当前服务已注册该路由；“未发现”表示接口资料与服务定义均未找到，不能代替源码结论。表中开发约定仍是目标行为，已提供入口不代表完整满足约定。

前端接入：账户页已接入真实列表及新增、编辑、启停、删除、重置接口，刷新后通过现有身份接口恢复有效会话。页面按两角色职责显示操作。账户写入已完成拦截响应的页面流程检查，真实写入及运维员的后端权限仍待试用验证。

## 1. 通用约定

| 项目 | 约定 |
| --- | --- |
| 基础路径 | `/admin-api`，下文路径均相对此路径 |
| 认证 | 除登录外，携带 `Authorization: Bearer <accessToken>` |
| 数据格式 | JSON；密码相关响应设置 `Cache-Control: no-store` |
| 成功响应 | `{ "code": 0, "data": ..., "msg": "" }` |
| 失败响应 | 对应 HTTP 状态，`code` 非零，`data` 为 `null`；`msg` 为提示，`errorKey` 为错误标识 |
| ID | 后端生成，接口统一使用非空字符串 |
| 时间 | `YYYY-MM-DD HH:mm:ss`，时区 `Asia/Shanghai`；未知值返回 `null` |
| 分页 | `page` 从 1 开始，返回筛选后的 `total` 与当前页 `items` |

核对结果：成功包装、Bearer 认证、账户字符串 ID 已在读取请求中验证。失败响应尚未统一，未认证请求返回 HTTP 401 与 `{ "detail": "missing bearer token" }`；登录响应未见 `Cache-Control: no-store`。

失败响应示例：

```json
{
  "code": 403,
  "data": null,
  "msg": "运维员不能重置管理员密码",
  "errorKey": "TARGET_ROLE_FORBIDDEN"
}
```

## 2. 角色权限

角色为管理员 `admin`、运维员 `operator`。后端须校验操作人的当前权限及目标账户的当前角色。

| 操作 | 管理员 | 运维员 |
| --- | --- | --- |
| 查看全部账户列表 | 允许 | 允许 |
| 新增账户、分配角色 | 允许 | 禁止 |
| 编辑姓名、角色 | 允许 | 禁止 |
| 启用、禁用账户 | 允许 | 禁止 |
| 删除账户 | 允许 | 禁止 |
| 重置管理员密码 | 允许 | 禁止 |
| 重置运维员密码 | 允许 | 允许 |
| 修改本人密码，验证原密码 | 允许 | 允许 |
| 查看监控、调用日志、审计 | 允许 | 允许 |
| 读取、修改阈值 | 允许 | 禁止 |

新建账户及密码重置后，可直接使用设置的密码登录并按角色权限使用功能。本人改密为用户主动操作。

权限实现状态：管理员登录、账户列表及审计读取已验证。运维员列表权限、密码重置的目标角色限制及其他账户写权限均待验证，不能根据管理员请求成功推断。

## 3. 数据字段

### 账户对象 `Account`

| 字段 | 类型 | 说明 | 实现状态 |
| --- | --- | --- | --- |
| `id` | string | 唯一 ID | 已返回字符串 |
| `username` | string | 唯一登录名，创建后不可修改 | 已返回；唯一性及禁止修改待验证 |
| `displayName` | string | 姓名或显示名称，必填 | 已返回；必填校验待验证 |
| `role` | string | `admin` / `operator` | 当前返回 `admin`；运维员待验证 |
| `roleLabel` | string，可选 | 管理员 / 运维员，也可由前端映射 | 账户列表未返回，可由前端生成 |
| `enabled` | boolean | 是否启用 | 已返回布尔值；启停效果待验证 |
| `createdAt` | string / null | 创建时间 | 当前样例为 `"—"`，需按约定返回时间或 `null` |
| `updatedAt` | string / null，可选 | 最近修改时间 | 当前账户响应未返回 |
| `lastLoginAt` | string / null | 最近成功登录时间，从未登录为 `null` | 已返回时间字符串；未登录账户空值待验证 |

### 密码请求字段

| 字段 | 使用接口 | 说明 | 实现状态 |
| --- | --- | --- | --- |
| `initialPassword` | 新增账户 | 管理员输入的初始密码 | Apifox 创建示例未包含，是否支持待确认；当前页面不提交此字段 |
| `newPassword` | 重置密码、本人改密 | 新密码 | 重置路由未声明请求体，是否读取该字段待确认；当前页面按无请求体重置；本人改密入口未发现 |
| `oldPassword` | 本人改密 | 当前密码 | 本人改密入口未发现 |

密码由后端安全哈希存储。账户响应、日志和审计不得包含明文密码、密码哈希或 Bearer Token；Token 仅在登录成功响应中返回。

## 5. 接口明细

### A01 账户列表

`GET /system/user/page`。管理员、运维员可调用。

| 查询参数 | 类型 | 说明 |
| --- | --- | --- |
| `page` | integer | 默认 1，最小 1 |
| `pageSize` | integer | 默认 10，最大 100；支持 10 / 20 / 50 |
| `keyword` | string，可选 | 对用户名、姓名进行包含匹配 |
| `role` | string，可选 | 精确匹配 `admin` / `operator` |
| `enabled` | boolean，可选 | `true` / `false`，未传表示不限 |

条件组合生效。按创建时间倒序、ID 作为次排序，空创建时间的排序位置固定。返回 `{ items: Account[], total: number }`；无结果或超过末页时 `items` 为空，`total` 保留筛选后的总数。

已验证情况：`/system/user/page` 支持 `pageNo`、`page`、`pageSize`、`keyword`，返回 `{ list, total }`；另有 `/system/user/console-page` 支持 `page`、`pageSize`、`keyword`，返回 `{ items, total }`。两者对 `role=operator`、`enabled=false` 的筛选实测均未生效。当前列表基线仅 1 个管理员账户，尚不能验证多页顺序、页大小上限及同时间排序规则。

### A02 新增账户

`POST /system/user`。仅管理员可调用。

```json
{
  "username": "ops.demo",
  "displayName": "测试运维员",
  "role": "operator",
  "initialPassword": "<初始密码>"
}
```

四项均必填。新账户默认启用，`lastLoginAt` 为 `null`。用户名重复时拒绝创建；字段和密码校验通过后完整创建账户。返回新建的 `Account`，包含真实 `id`。

### A03 编辑账户

`PUT /system/user/{id}`。仅管理员可调用。

```json
{
  "displayName": "更新后的姓名",
  "role": "operator"
}
```

支持部分更新，未传字段保持原值。允许字段为 `displayName`、`role`、`enabled`；空请求、未知字段及无效值返回参数错误。返回更新后的 `Account`。密码通过专用接口修改。

角色变更须使该账户原权限失效，避免原会话继续按旧角色访问。

### A04 启用、禁用

`PUT /system/user/{id}`。仅管理员可调用，请求为 `{ "enabled": true }` 或 `{ "enabled": false }`。返回更新后的 `Account`，重复设置相同状态不切换状态。

禁用后拒绝新登录和已有会话访问；启用不恢复已撤销的 Token，也不重置密码。

### A05 删除账户

`DELETE /system/user/{id}`。仅管理员可调用，无请求体，成功返回 `true`。

删除后拒绝登录并使已有会话失效。历史审计及操作人、目标信息保留。目标不存在时返回 404。

### A06 重置密码

`POST /system/user/{id}/reset-password`。管理员可重置两类账户，运维员只能重置运维员账户。

```json
{
  "newPassword": "<新密码>"
}
```

无需目标账户原密码。后端按目标账户当前角色校验权限；运维员重置管理员密码时返回 403。重置不能改变角色、启用状态或其他资料。

响应为 `{ "id": "example-user-id", "sessionsRevoked": true }`。全部旧会话失效后方可返回 `sessionsRevoked: true`；重置本人密码时也包括当前会话。启用的账户可直接使用新密码重新登录。

### A07 当前账户及会话校验

`GET /system/auth/me`。已登录用户可调用，无请求体，用于恢复身份和获取当前权限。

现有等价接口为 `GET /system/auth/get-permission-info`，已验证带有效 Token 返回当前账户和权限，无 Token 返回 401。可将本文 A07 映射到该接口，无需为路径一致而重复实现；权限编码仍需按两角色职责核对。

| 返回字段 | 类型 | 说明 |
| --- | --- | --- |
| `account` | Account | 当前账户 |
| `permissions` | string[] | 当前账户权限编码 |

返回当前有效身份；Token 无效、会话已注销、账户禁用或删除时返回 401。`permissions` 仅描述操作权限，密码重置仍须校验目标角色。

### A08 修改本人密码

`POST /system/auth/change-password`。已登录用户可调用。

```json
{
  "oldPassword": "<当前密码>",
  "newPassword": "<新密码>"
}
```

目标账户取自当前会话，不接受指定其他账户 ID。验证原密码和新密码规则；校验失败不修改密码。成功后撤销本人全部旧会话，返回 `{ "reauthenticationRequired": true }`，用户以新密码重新登录。

### A09 登录

`POST /system/auth/login`。无需 Token。

```json
{
  "username": "ops.demo",
  "password": "<密码>"
}
```

| 返回字段 | 类型 | 说明 |
| --- | --- | --- |
| `accessToken` | string | 登录凭据 |
| `account` | Account | 当前账户 |
| `permissions` | string[] | 与 A07 一致的权限编码 |

有效账户和密码验证通过后返回凭据。无效凭据或禁用账户拒绝登录；失败响应不得包含 Token。

### A10 注销

`POST /system/auth/logout`。已登录用户可调用，无请求体，成功返回 `true`。当前会话立即失效。

### A11 审计查询

`GET /system/audit-log/page`。管理员、运维员可调用。

查询参数：`page`、`pageSize`、`operator`、`action`、`result`、`startTime`、`endTime`。页码从 1 开始，默认每页 20 条，最大 100 条；筛选可组合，`result` 为“成功”或“失败”。

返回 `{ items: AuditRecord[], total: number }`。每条记录包含 `id`、`operatedAt`、`operator`、`role`、`roleLabel`、`action`、`target`、`beforeValue`、`afterValue`、`result`、`sourceIp`、`sessionId`。

后端记录账户创建、编辑、角色变更、启停、删除、密码重置、本人改密、登录成功或失败、注销及被拒绝的账户写操作。密码事件只记录“密码已变更”等非敏感信息。

## 6. 错误约定

| HTTP 状态 | errorKey | 场景 |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | 字段、密码不合法或空更新 |
| 400 | `OLD_PASSWORD_INCORRECT` | 本人改密时原密码错误 |
| 401 | `UNAUTHENTICATED` / `INVALID_CREDENTIALS` | 会话失效或登录凭据错误 |
| 403 | `FORBIDDEN` / `TARGET_ROLE_FORBIDDEN` | 无操作权限或目标角色不允许 |
| 404 | `ACCOUNT_NOT_FOUND` | 目标账户不存在 |
| 409 | `USERNAME_EXISTS` | 用户名重复 |
| 409 | `LAST_ADMIN_PROTECTED` / `SELF_OPERATION_FORBIDDEN` | 触发管理员保护规则，规则确定后使用 |
| 500 | `INTERNAL_ERROR` | 服务端失败 |

## 7. 待确定参数

| 项目 | 待确定内容 |
| --- | --- |
| 字段校验 | 用户名、姓名的长度和字符要求；用户名大小写及空格处理 |
| 密码策略 | 长度、字符要求、是否禁止与当前密码相同，以及初始和重置密码的交付方式 |
| 会话策略 | 空闲时长、绝对有效期、续期方式；角色变更后如何撤销旧权限 |
| 管理员保护 | 是否禁止删除、禁用或降级本人及最后一个启用管理员；规则须覆盖并发操作 |
| 删除策略 | 软删除或物理删除，删除后用户名能否复用 |
| 权限编码 | `permissions` 中各操作的编码及角色映射 |
| 审计细节 | 动作词表、操作人匹配方式、时间筛选边界、来源 IP 解析及写入与审计的一致性 |
