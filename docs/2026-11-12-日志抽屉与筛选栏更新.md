# 日志抽屉与筛选栏更新

后续接口名称、耗时移除及四页布局见 [最新四页更新](2026-11-12-四页紧凑布局更新.md)。

按 [20261112 开发文档](<20261112-ABIS mock界面开发文档.md>) 的最新 §1.5–1.9 实现，保留 15 条请求、两组三候选和已有未提交改动。

页面内容从筛选栏开始，导航继续高亮日志查询。桌面第一行为请求 ID、用户 ID、时间范围和查询/重置；第二行为接口类型、模态、执行状态和总耗时范围，字段标签在左侧。窄屏按相同顺序换行。

请求详情顶部为紧凑信息表格：请求 ID 通栏，用户 ID 与接口类型同行，接收时间通栏，执行/发布状态同行，两个耗时同行，业务摘要通栏。同步省略发布状态和重复的 ABIS 耗时。窄屏字段自然换行。表格与下方详情区等宽、相隔 20px；详情区使用浅边框和浅灰标签栏。

处理过程直接显示阶段。异步成功完成时默认折叠；处理中、待重试和待核查展开关注环节；ABIS 业务失败同时展开外层调用及内层处理。历史异常恢复后按成功处理，仍保留原 Event。同步直接显示三个 Event。用户手动状态在两个标签间切换时保留。

ABIS 接口报文包含“请求参数”“响应结果”两个可独立展开的项目，默认均折叠，支持同时打开。正文按实际调用尝试关联，使用格式化 JSON 和内部滚动；缺失时分别提示“暂无请求参数记录”“暂无响应正文记录”。确定未发送的 U005 不生成入参记录。多次尝试可在公共选择器切换，报文与图像比对使用同一选中尝试；不回退使用其他尝试的正文。

修改涉及 `RequestLogDrawer.vue`、`RequestLogProcess.vue`、`RequestLogStage.vue`、`LogView.vue`、`AdminLayout.vue`、主题中的旧日志筛选布局、日志 Mock 的请求正文及契约/工具函数。沿用现有本地图像与共享当前入库数据，真实后端取图仍待对接。
