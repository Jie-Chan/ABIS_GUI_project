# 11 月 16 日复审：布局与调用方式

依据《20261116-ABIS mock界面开发文档.md》本轮复审新增要求，在现有未提交代码上继续修改。用户提供的开发文档和登录参考图均保留，未执行 Git commit。

## 本轮变化

- 日志列表接口类型只显示「人脸注册」「指纹 1：N查重」等业务名称，移除同步、异步附标及占位。请求详情在接收时间之后增加通栏「调用方式」，读取已有 `mode` 字段显示「同步」「异步」，其他值或缺失显示「未记录」。接口类型不重复附加方式。接口契约同步说明历史缺失情况。
- 时间线移除「接收 Stage 在此完成」「落库后」「本次调用前」等顺序复述，保留 `PENDING`、`CALLING` 状态、实际时间、调用方、ACK 和 MQ 发布交付结果。
- 申请人变更记录直接从表头开始。窄屏人脸缩略图高度收紧为 96 px，缩小人脸与指纹组间距，保留完整等比显示、分值和预览；624×850 下首屏可完整看到 U301 左手前四指。
- 审计单列筛选使用统一的 72 px 标签宽度，时间、操作人、操作类型和结果的控件左边缘对齐。桌面日期输入仍约 400 px。
- 阈值配置采用主卡片顶部的唯一标题；两项桌面等宽并排铺满表单，窄屏按人脸、指纹顺序单列。优先规则靠近输入，按钮紧接表单，移除独立标题、分隔线及页底说明区。保存、默认值、未保存状态、离页提醒和回读保护保留。
- 登录侧脸保留鼻梁、唇线及下颌的局部浅色轮廓，缩短突出的额头与颈部轮廓，上下两端渐隐融入细线背景。标题、表单及左下指纹布局沿用对照参考图后的版本。

## 手动验收入口

预览使用 `npm run dev:mock -- --host 0.0.0.0`，访问 `http://服务器IP:5186/login`。管理员 `admin / admin123`，运维员 `ops.zhang / ops123`。

在日志查询按完整请求 ID 查询：

| 请求 ID | 验收场景 |
| --- | --- |
| `REQ-00000001` | 列表「人脸注册」，详情调用方式「异步」 |
| `REQ-00000013` | 列表「人脸删除」，详情调用方式「同步」；桌面首屏三个事件标题 |
| `REQ-00000014` | 接收、落库和 MQ 发布事件的实际信息；三名指纹候选 |
| `REQ-00000015` | 三名人脸候选 |
| `REQ-00000016` | 复用原缺用户 ID 的历史样例，调用方式未记录；详情分别显示「未记录」和「—」 |

默认日志仍为 15 条。`REQ-00000016` 仅通过完整 ID 查询，不计入默认范围；重置后恢复 15 条。申请人可查询 `U301`，在 624×850 下打开当前图像核对人脸与前四指，再打开入库变更记录逐条查看对应日志并返回。

## 实际验证

`npm run build:mock` 通过，本轮 **81 项相关自动化检查通过**，浏览器错误和真实后端调用均为 0：

| 验证脚本 | 检查数 |
| --- | --- |
| `review-console-20261116-followup.mjs` | 8 |
| `review-request-logs.mjs` | 26 |
| `review-log-images.mjs` | 16 |
| `review-console-20261113.mjs` | 18 |
| `review-sync.mjs` | 13 |

专项包含缺失调用方式的边界样例、两个桌面视口的图像剩余空间、变更精确跳转与返回、审计日期和下拉、阈值校验与保存及登录背景人工复核。之后增加真实 `REQ-00000016` 样例并独立通过 UI 检查：查询 1 条、调用方式「未记录」、用户 ID「—」，重置恢复默认 15 条。其余页面未重复执行前轮全套检查。

实际布局测量：

- 624×850 的 U301 左手前四指卡片最大下边缘为 772 px，质量分条下边缘为 771 px；无需滚动可见，人脸图像完整。其余指位可滚动查看并放大。
- 624×850 审计四个筛选控件左边缘均为 117 px，日期、下拉、查询和重置可用。
- 阈值字段在 1422 px 下各宽 631 px、1280 px 下各宽 580 px，624 px 下单列宽 534 px。输入区至优先说明 12 px、说明至操作按钮 16 px。
- 1422×804 和 1280×720 下，新增调用方式行后，指纹与人脸比对图框仍等高同顶；1280 下图框高约 102 px、用户 ID 下边缘 621 px。三个候选逐一切换正常，切标签保留所选候选。
- 登录在 1440×900、1280×720、390×844 下完成截图复核；局部鼻唇下颌及两端渐隐可见，表单区保持清晰，桌面标题组宽度仍为输入宽度的 87%。
