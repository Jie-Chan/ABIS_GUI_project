# 登录页视觉还原第二版

依据 [登录页设计示意](20261116-ABIS登录页设计示意.png) 再次调整登录页，重点校准背景形态、字体和视觉质感。保持已有表单、登录和其他页面功能，保留之前全部未提交改动，未执行 Git commit。

## 实现

- 从原图制作干净的背景素材，清除中央标题、字段及按钮，保留侧脸的自然鼻唇和下颌、流线疏密、指纹的回旋与分叉和朦胧浅蓝灰底色。
- 页面叠加真实 HTML 表单。桌面保留最新文档要求的局部轮廓和上下渐隐；窄屏分别裁切两侧图形，使用横纵渐变衔接背景，消除裁片矩形硬边。
- 标题使用本机 Noto Sans CJK SC Black 的 ABIS 四字母 WOFF2 子集，真实 900 字重，保证浏览器显示一致。ABIS 与中文间距为 13 px，标志与 ABIS 间距 18 px。
- 保留 400 px 表单和 48 px 控件；标题下距调整为 44 px，输入边框改为灰蓝，按钮采用轻微蓝色渐变与顶部亮度变化。窄屏标题完整居中。

同为 1585×992 对照时，侧脸与指纹形态、标题厚度及间距明显接近示意图；仍有轻微背景明暗和按钮质感差别。局部轮廓渐隐按复审要求保留。

## 实际验证

`npm run build:mock` 通过。本轮 13 项登录专项和 15 项登录及个人信息回归，共 **28 项功能检查通过**，浏览器错误及真实后端调用均为 0。

覆盖 1585×992、1440×900、1280×720、390×844、320×844：标题与字段居中、输入与按钮等宽且高48px、标签左对齐、无横向溢出，空输入及错误密码在表单内反馈，正确密码可通过 Enter 登录。另验证登录 redirect，以及加载期间重复 Enter 和提交只调用一次登录接口。个人信息回归包含改密、重新登录和角色权限。

在 1585×992 下，标题组宽348px、水平中线792.5px；用户名、密码输入框上缘为441.5px、541.5px，按钮上缘619.5px，尺寸均400×48px。桌面标题与表单宽度比保持87%。

同尺寸截图另作人工视觉对照，检查侧脸自然度、指纹回旋、背景光感、标题字重与间距。初次验收发现移动端裁片硬边，修复后重新查看390/320正常及错误共4张截图，确认硬边消失、表单和错误清晰，未重复全套功能用例。

报告及截图位于忽略提交的 `frontend-toolkit/verification/qa-output/login-reference-v2-20261116/`；裁片修复的最终复核结果为该目录 `mobile-mask-review.json`。个人信息回归日志为 `qa-output/login-v2-profile-20261116.log`。

## 背景生成提示词

模式：内置 `image_gen`，精确保留式编辑；`referenced_image_paths` 指向原设计图，`transparent_background: false`。

```text
Use case: precise-object-edit.
Asset type: production background image for this existing ABIS login page.
Input image 1 is the EDIT TARGET, not merely a style reference. Perform a strict preservation edit of this exact image.
Change only the central login UI: completely remove the blue four-square logo, ABIS and Chinese product title, username and password labels, both input rectangle outlines and their white fills, the blue login button, all characters and any associated drop shadows. Seamlessly inpaint those exact positions with the same soft pale blue-gray misty gradient already surrounding them.
Preserve all existing background content and composition: the natural left-facing facial profile along the right edge, its nose bridge, lips and chin details, the densely spaced flowing curves of the face, the authentic curved and branching fingerprint ridges partly cropped at the bottom-left, their scale, placement, relative cropping, subtle contrast and light blue colors, and the original cloudy gradient background texture. Do not redraw, redesign, simplify or relocate these edge decorations. Do not add details, objects, patterns or symbols.
Keep the source's 1585-by-992 landscape aspect ratio and all relative positions. The middle 35%–65% of image width must be clean, uninterrupted background for a real HTML form.
Output is background only: absolutely no text, letters, numbers, logos, icons, input fields, buttons, watermarks, UI outlines or residual shadow shapes. Opaque background; no transparency.
```
