## 访问与演示

在项目根目录使用 Node 22.23.4 或兼容版本启动：

```bash
npm run dev:mock -- --host 0.0.0.0
```

另一台电脑访问 `http://<服务器IP>:5186`。服务状态为 `/monitor`，主机资源为 `/host-resources`，其他页面为 `/logs`、`/applicants`、`/audits`、`/threshold`。登录演示账户 `admin / admin123`。本轮自动化使用独立的本地 5187 端口，验证完成后关闭测试服务。

| 页面 | 本轮行为与演示入口 |
| --- | --- |
| 日志查询 | 桌面七项筛选分两行，增加响应发布状态；窄屏默认只显示双 ID、时间与查询操作，其余放入带已生效条件计数的「更多筛选」。默认仅查询 15 条；输入完整 ID 可查询历史及补充样例。 |
| 日志详情 | REQ-00000012 显示「查重成功 · 响应待发布」，从 PUBLISH_NACK 的「查看事件」展开并定位发布异常。REQ-00000011 显示「查重失败 · 失败响应已发布」。同步 REQ-00000013 首屏可见三个事件标题。 |
| 补充日志 | 按 REQ-00000016 查询缺用户 ID 的记录；按 REQ-00000017 查询两次调用尝试。第一次确认未发送且没有正文，第二次使用实际请求及响应正文。重采阶段切换后，无 ID 查询仍限定 15 条。 |
| 图像比对 | 标题为「待查图像 / 候选图像」，排名和分数标注「本次响应」。明确区分失败、无候选、处理中和暂无结果；支持放大、保留候选及关闭后恢复。图像来源提示统一，关闭请求详情后重新打开默认候选 1。 |
| 申请人 | U001、U004、U301 分别显示 10/10、6/10、8/10 指；无指纹显示「指纹未入库」。按已删除的 U002 查询，从空态进入该 ID 的请求日志。重采面板优先显示 U301 / U302 / U303，标出当前阶段，U900 收入「旧样例」。通用 SVG 仅保留 Mock 水印。 |
| 监控 | face-1 显示实例探测时间及超时原因；minio-1 演示缺时间、缺原因。二者均可进入主机资源并定位突出算法 VM 1 或 MinIO VM。全局状态更新时间、实例探测时间及资源采集时间分别取值。 |
| 审计 | 时间控件保持约 400 px；操作人按完整账号匹配。登录动作统一为「登录」，成功或失败由结果表达，兼容原有样例。数量旁显示完整 Mock 日期覆盖范围。创建和禁用成功样例使用管理员。 |
| 阈值 | 人脸低于 60、指纹低于 40 时在对应输入框旁提示并禁用保存；60 / 40 有效。「填入默认值」只填入 60 / 60，保存确认后生效，保留未保存离开提示及读取失败保护。 |

三页查询共用连续白色主容器和固定筛选栏。日志桌面表头跟随筛选栏吸附，并保持表格列线对齐。日志、审计的列表、数量、分页和 CSV 共用最近一次成功查询的条件；仅编辑筛选控件不会改变结果或导出。查询失败保留上一轮结果及导出条件，迟到的旧请求不能覆盖新结果。CSV 导出全部结果页，日志接收时间保留毫秒。

## 验证结果

- `npm run build:mock` 通过；构建保留既有的单包体积提示。
- 18 个浏览器验证脚本共 247 项检查通过，覆盖本轮功能及原有账户、个人信息、日志、申请人、重采、监控和阈值交互。
- 所有脚本均无浏览器错误；包含后端请求监测的脚本均未访问真实后端。
- 1422×804、1280×720：日志关键列无需横向滚动，同步三个事件标题及查重图像、用户 ID、排名、分数、指位首屏可见。
- 桌面及窄屏的零条、少量及正常结果使用相同底部内边距，主容器随内容自然缩短。
- 1422 / 1280 / 624 px：三页记录首屏、滚动 40 px、列表中段及回到顶部的筛选栏坐标相同，表格记录实际移动，白色主容器及内容左右对齐。
- 624×850：三页均能在单月面板选跨月日期和时分秒，确定 / 清空可操作，范围确认后需查询才生效；补查 390 / 320 px 的查询栏和日期面板边界，320×600 时日历内容可滚动且确定 / 清空仍可见。
- 1422 / 1920 px：审计时间输入约 400 px，完整日期时间可读，控件保持紧凑单行。
- 1024×900：监控三张服务卡片及四行存储全部首屏可见；内容容器宽 736 / 560 / 480 px 时分别为三列、两列加通栏、单列。

新增验证脚本为 `review-current-spec.mjs`、`review-responsive-query.mjs`、`review-query-empty-states.mjs`；原有脚本按本轮默认日志范围、单月面板、登录动作、阈值按钮和异常摘要同步更新。可在 `frontend-toolkit/verification` 中执行：

```bash
ABIS_PREVIEW_URL=http://127.0.0.1:5186 npm test
```
