# 2026-11-18 主机资源 121 联调

从「监控 → 主机资源」进入，标题、表头和 8 台主机的概览行在同一张卡内，默认收起。展开应用服务器 01（121）可在四张趋势图上方看到「采集于 HH:mm:ss」。断采时该行保留最后的数值、采集时间和曲线。读取错误可在行内重试。服务状态页使用现有 Mock 数据和主机链接。[补充开发文档](<20261118-ABIS mock界面补充开发文档.md>)

## 运行与配置

使用 Node.js 22，在项目根目录运行 `npm run dev:mock -- --host 0.0.0.0`。登录后，从「监控」菜单进入。带 `hostId` 的链接会定位对应主机，`app-1` 会自动展开，未知 ID 显示提示。本轮验收使用本机回环端口 `5196`，验收后关闭。以下入口在启动 5186 后可访问。[主机资源](http://10.200.51.121:5186/host-resources) · [app-1 深链](http://10.200.51.121:5186/host-resources?hostId=app-1) · [算法服务 VM1 深链](http://10.200.51.121:5186/host-resources?hostId=algorithm-vm-1)

当前 Hub 地址和主机映射由 `config/beszel.json` 配置。凭据沿用进程环境或 Git 忽略的 `.env.demo.local`。[当前配置、五档查询及验收](2026-11-19-主机映射与历史趋势联调.md)

`GET /abis-admin/monitor/hosts` 由内网 Vite Mock 提供。页面入口和适配器沿用 `MONITOR_VIEW`。以下联调样本来自 121 当时最近一小时的 `1m` 记录。正式 ABIS 管理服务的接口和服务端授权需在对应环境验收。[Beszel v0.21.2 字段定义](https://github.com/henrygd/beszel/blob/v0.21.2/internal/entities/system/system.go) · [磁盘延迟计算](https://github.com/henrygd/beszel/blob/v0.21.2/agent/disk.go#L697-L726)
