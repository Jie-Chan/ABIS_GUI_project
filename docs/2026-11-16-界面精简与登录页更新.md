# 11 月 16 日版：界面精简与登录页更新

按《20261116-ABIS mock界面开发文档.md》的新增要求开发，基于 `ebcd11d` 继续修改。原开发文档保留，本轮未执行 Git commit。

## 本轮变化

- 日志已完成请求的「请求耗时」仅显示数值及单位；仍在累计的请求保留「已用时」。抽屉耗时和 CSV 口径保留。
- 查重候选切换区直接排列候选按钮，仅右图保留「候选图像」标题。按钮组仍有「切换候选图像」无障碍名称，候选顺序、分数、当前入库图像时点提示及切换状态保留。
- 接收请求事件移除复述接收动作的样例句，时间、业务对象、接口及调用方照常展示。响应发布保留 MQ 确认及响应未退回的交付结果。
- 申请人当前图像按左手、右手分组，卡片仅显示拇指、食指等短名称；缩略图无障碍名称和放大预览仍显示完整手别。入库变更移除独立模态列，通过「人脸注册」「指纹删除」等完整操作名称表达，指位数、时间及精确日志跳转继续可用。
- 审计登录、登出、重置密码等非变更详情省去前后值；修改阈值等变更事件并列显示前后值，适用但未记录的值显示「—」，数值 0 保留。
- 阈值页只有一处标题，移除面包屑和常驻「保存后生效」。保存确认标题为「保存阈值修改？」，只列实际修改项及原值 → 新值，底部为「取消」「保存」。下限、未保存状态、填默认值、离页提示和回读失败保护继续保留。
- 个人资料直接显示字段表，用户名、角色各一处。新密码提示统一为「新密码至少 7 位」，复用同一位置反馈错误，保留 6/7 位边界和改密后重新登录。
- 登录页将四格标志与产品名称作为整组标题，与字段和登录按钮居中；移除欢迎、副标题、重复输入提示和页脚。错误放在表单内，保留无障碍字段关联、回车提交、加载防重和原有登录跳转。浅蓝灰背景使用左下裁切指纹及右侧朝向表单的低对比侧脸线条。

已对照补传的 [登录页设计示意](20261116-ABIS登录页设计示意.png) 进一步调整登录页。标题使用 36 px 四格标志、44 px ABIS 和 34 px 中文名称，桌面组宽仍为 348 px；输入与按钮均为 400×48 px。移除输入框左侧图标，按参考收紧字号与间距。左下指纹缩至角落并增加细密纹路，右侧侧脸向内定位，背景使用沿额头、鼻唇及下颌延伸到底边的连续流线。背景以原生 SVG 和 CSS 绘制。
