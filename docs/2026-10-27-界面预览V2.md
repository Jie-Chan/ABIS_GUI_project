# ABIS GUI 第二版 Mock 界面

本版位于 `front-end` 分支，按审阅通过的第二版示意图实现。

## 预览

使用满足当前 Vite 要求的 Node.js 版本运行：

```bash
npm run dev:mock
```

访问 `http://localhost:5186/login`。演示账户仍为 `admin / admin123`（管理员）、`ops.zhang / ops123`（运维员）。构建使用 `npm run build:mock`。

Mock 开发服务固定使用 5186，并启用 `strictPort`。2026-10-27 排查发现 Windows 的 `localhost:5174` 被 VS Code 转发到了另一份 hybrid 联调服务，因此改用独立端口；未停止或修改该联调服务。

## 界面调整

- 登录区域水平居中，取消左右分栏及外围卡片，将装饰图移至背景边缘。Mock 标识和演示凭据继续显示。
- 顶部主导航为服务状态监控、日志查询、审计查询、设置；设置内包含匹配阈值配置和账户管理。
- 导航项仍从原权限表过滤。运维员看不到设置入口，原受限路由继续被守卫拦截。
- 设置下拉支持鼠标和键盘；进入设置内页面时显示对应选中态和位置提示。
- 消息提示根据实际顶部导航高度调整位置，避免遮挡导航。
- 窄屏使用可滚动的顶部菜单和表格。账户操作列在窄屏取消固定，避免遮住用户名与数据。

## 账户列表字段

| 字段 | 中文列名 | 展示规则 |
| --- | --- | --- |
| `id` | 账户 ID | 直接展示 |
| `username` | 用户名 | 直接展示 |
| `role` | 角色 | `admin` 为管理员，`operator` 为运维员 |
| `enabled` | 启用状态 | 显示启用/禁用标签 |
| `createAt` | 创建时间 | 优先使用 `createAt`，兼容现有 `createdAt`，缺失显示「—」 |
| `updateAt` | 更新时间 | 缺失显示「—」，不生成虚构时间 |
| `lastLoginAt` | 最近登录时间 | 缺失显示「—」 |

列表移除姓名列，保留原有操作列。字段兼容只用于渲染，不改写原始记录，也不回写接口别名。新建/编辑表单仍按原契约保留姓名字段与校验，本轮未变更提交载荷。

## 验证

使用 Node.js 22.23.2、Chromium 和 Playwright 验证：

- Mock 构建通过。
- 46 项浏览器检查通过。
- 覆盖登录必填及错误密码、登录居中、设置的键盘展开与导航选中态、监控统计及刷新保留展开状态。
- 覆盖账户中文列顺序、角色映射、`createdAt` 兼容、`createAt` 优先级、`updateAt` 有值/缺失的显示、账户搜索、新建/编辑及原校验、取消删除/禁用/重置密码。
- 覆盖阈值下限校验和取消保存、日志与审计详情及导出、退出确认、运维员导航和两个受限路由。
- 五个管理页面在 1280、1024、768、390、320px 宽度检查页面溢出，另检查 1600px 桌面布局；登录在 390/320px 检查居中；检查手机账户的用户名不被操作列遮挡。
- 浏览器报错为 0，Mock 流程没有向真实后端发送请求。

`src/api/`、`src/stores/`、`src/router/`、原业务常量与 Mock 数据均未修改。登录及账户业务脚本、退出处理函数与本轮开始时保持一致。未执行真实后端联调。
