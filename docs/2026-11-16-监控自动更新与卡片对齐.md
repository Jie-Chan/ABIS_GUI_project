# 2026-11-16 监控自动更新与卡片对齐

依据 [最新开发文档](<20261116-ABIS mock界面开发文档.md>) §3.2、§3.4、§10.1、§10.2 实现。保留此前未提交的视觉、排序及审计功能，本轮未提交 Git。

## 页面行为

- 服务状态打开即读取，停留期间沿用现有接口和轮询间隔在后台持续更新。正常获取后标题右侧显示圆点和「监控中」，不再展示全局更新时间、手动刷新、频率或倒计时。
- 后台读取期间保留可操作的既有结果，不增加列表遮罩。更新失败时显示「监控数据暂未更新」，保留计数、实例状态和当前筛选；重试开始不会提前清除中断提示，只有成功取得新结果才恢复「监控中」。
- 首次未能取得数据时显示「监控数据暂不可用」，汇总分值保持「—」，后续后台读取成功后自动恢复。首次读取中显示「正在读取」。
- 慢请求在进行中时复用同一读取，防止轮询重叠。离开监控页停止定时读取，迟到响应不覆盖现有结果；重新进入时重新获取数据，异常/未知筛选及主机定位联动保持。
- 首页异常信息使用业务说明：`face-1` 为「异常／服务未响应」，`minio-1` 为「未知／原因未记录」。移除「最近探测」、健康探测超时及等待秒数，保留状态、说明、主机资源入口与部署信息。
- 容器大于 660px、默认三卡各两条时，共享标题及两行网格轨道。卡头同高、每卡两行等高、跨卡分隔线对齐；异常说明换行时，两行按最长内容同步增高，不裁切说明和操作。736、560、480px 的三列、两列加通栏、单列规则及筛选少量结果的自然高度保留。
- 1440 × 900、1920 × 1080 的全正常页面继续利用首屏，默认异常样例保持自然留白。Mock 初始仍为 10 项：8 正常、1 异常、1 未知，不加入无业务依据的随机状态变化；自动状态变化、失败和恢复用测试中的受控接口快照验证。

## 修改文件

- `src/views/MonitorView.vue`：监控提示、后台无阻塞展示、共享行高与分隔线。
- `src/stores/monitor.js`：进行中读取复用、失败保留和迟到保护。
- `src/components/MonitorProbe.vue`、`src/mock/monitor.js`：精简业务说明，移除探测时间展示。
- `frontend-toolkit/verification/review-monitor-live.mjs`：新增自动更新及布局专项；相关旧检查同步新入口和文案，边界快照验证仍通过现有 store 读取。

## 验证

使用本机 Node 22，`npm run build:mock`、JS/Vue 编译及 `git diff --check` 通过。专项及相关回归共 44 项通过，浏览器错误和真实后端请求均为 0，同一检查的重复运行不重复计数。

| 检查 | 通过项数 | 范围 |
| --- | ---: | --- |
| 新增 `review-monitor-live.mjs` | 9 | 自动状态变化、筛选保持、后台无遮罩、慢请求复用、中断/恢复、首次失败/恢复、离页停止/迟到忽略、三卡对齐/长说明/容器布局、主机返回 |
| `review-monitor.mjs` | 9 | 原监控计数、筛选、未知/无数据、失败保留及恢复、响应式不遮挡 |
| `review-visual-20261116.mjs` | 11 | 对比度、请求摘要、日志表格/导航、阈值、长短表、全正常监控首屏和图像质量分回归 |
| `review-ux-20261116.mjs` | 15 | 原排序/筛选、CSV、跨页恢复、申请人日志联动、核查/复制、质量分、审计、主机跳转及会话契约回归 |

在 1440 × 900 和 1920 × 1080 下，正常、异常、长说明共六种场景的卡头均同高；对应行及分隔线对齐，各卡两行高度差不超过 1px。长说明可完整阅读，主机入口不裁切。736、560、480px 容器及单条筛选的自然布局也已验证。

后台行为报告和原始截图在被 Git 忽略的 `qa-output/monitor-live-20261116/`；回归报告分别为 `qa-output/monitor-live-old/`、`monitor-live-visual/`、`monitor-live-ux/`。

在 `frontend-toolkit/verification` 下运行 `ABIS_PREVIEW_URL=http://127.0.0.1:5186 npm run test:monitor-live`。测试把现有轮询计时器临时加速并控制返回快照，验证真正的后台触发与失败恢复；不修改产品实际间隔，也不新增首页演示控件。浏览器测试数据互相隔离，默认页面数据不受测试快照影响。

页面入口为登录后的 `/monitor`，管理员 `admin / admin123`。通过服务器原 Mock 启动命令访问 5186；本轮临时测试服务使用 5187，结束后停止。
