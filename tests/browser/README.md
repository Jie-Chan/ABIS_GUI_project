# 浏览器回归

独立 Playwright 包，运行依赖不进入产品构建。所有 API 请求在浏览器内拦截，未声明的 API 与外部请求直接拒绝，既不读取也不写入真实后端账户。

```bash
# 工程根目录
npm ci --prefix tests/browser
npm exec --prefix tests/browser -- playwright install chromium
npm run dev -- --host 127.0.0.1 --port 5190
# 另一个终端，同样位于工程根目录
npm run test:e2e
```

可设置 `ABIS_TEST_URL=http://127.0.0.1:5191` 指向生产构建预览服务。测试不依赖 Vite 源码模块，当前 120 项检查覆盖登录、会话恢复/过期、新权限与设置导航、管理员目标保护及本人/管理员角色锁定、禁用按钮置灰和已禁用管理员恢复、账户可选资料、个人信息菜单和本人改密（长度提示及 5/6/7 位边界、成功、原密码错误、接口缺失和密码清理）、账户操作/空列表/错误、监控正常/异常二态卡片/授权与容量内容移除/实例直接可见、阈值保存和重置 60/60、CSV 文件流与失败响应，以及导航居中/字号/长名称、确认弹窗尺寸、登录背景和桌面/手机布局。

默认报告与截图写入本目录忽略的 `qa-output/`。可用 `ABIS_QA_OUTPUT_DIR` 覆盖路径。测试 fixture 仅存在于此开发测试包，应用的 `src/` 和构建产物不会包含测试数据或演示凭据。

监控专项位于 `monitor.mjs`，由同一次 `npm run test:e2e` 调用，复用 HTTP 请求拦截，不替换应用模块。覆盖全部/异常筛选与全量统计、刷新保留筛选、60 秒轮询及离页停止、授权与容量内容不展示、后端原始指标不影响健康展示、未知实例状态归入异常、动态新增服务、首次加载和读取失败、main 无效快照校验，以及 1600/1280/1024/768/767/390/320px 布局和长英文名称/层级/实例 ID 换行。
